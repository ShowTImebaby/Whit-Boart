# 📝 Бяла дъска (Whiteboard Web App)

Модерно, леко и функционално уеб приложение за организиране на идеи, бележки, задачи и медийни файлове върху интерактивна бяла дъска. Приложението работи изцяло в браузъра и запазва вашите данни локално.

---

## ✨ Основни функционалности

- **📂 Управление на проекти:** Създаване, преименуване и изтриване на множество независими проекти/дъски.
- **📝 Текстови бележки:** Добавяне на жълти лепящи бележки с възможност за промяна на размера на текста.
- **🖼️ Качване на снимки и файлове:** Вмъкване на изображения с преглед на пълен екран (Zoom) и файлови прикачени документи.
- **✅ Списъци със задачи (Checklists):** Интерактивни интерактивни списъци за отмятане на изпълнени задачи.
- **✍️ Рисуване със свободна ръка:** Режим за рисуване с интерактивен Canvas слой върху дъската.
- **🔗 Свързване на елементи:** Визуално свързване на изображения с текстови бележки или списъци с помощта на динамични стрелки/линии.
- **🔍 Мащабиране и навигация:** Поддръжка на Zoom (увеличение/намаление) и преместване (Pan) с мишка/тъчпад.
- **💾 100% Локално съхранение (Offline First):** Използва IndexedDB в браузъра за автоматично запазване на цялото състояние без нужда от сървър.
- **📱 Отзивчив дизайн (Responsive UI):** Оптимизиран интерфейс за настолни компютри и мобилни устройства.

---

## 🛠️ Използвани технологии

- **HTML5** (Семантична структура, Canvas API)
- **CSS3** (Flexbox, Grid, CSS Variables, Модерен дизайн)
- **JavaScript (Vanilla JS - ES6+)** (Без външни библиотеки и рамки)
- **IndexedDB API** (Локална база данни в браузъра)
